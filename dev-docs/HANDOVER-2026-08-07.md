## 六、⚠️ 重要警示：F401 副作用导入

**`ruff check --fix` 会误删"带初始化副作用的导入"（F401 误报），已造成 2 次事故：**
1. `veusz/windows/simplewindow.py` 的 `from .. import dataimport` 被删 → **embed_test 崩溃（WinError 10054）**，已修复（`80a57f24`，加 `# noqa: F401`）
2. `veusz/qtall.py` 的 loadUi/sip fallback 曾被删（已恢复）

**为什么是副作用**：`dataimport` 导入时通过 `registerImportCommand()` 动态给 `CommandInterface` 注册 `Import*` 命令（`commandinterface.py:45-49`）；`simplewindow.py` 被 `embed_remote.py` 子进程间接导入，删了它 → 子进程 `AttributeError: ImportFITSFile`（pythonw 静默崩溃）→ 父进程 10054。

**规则**：**不要对以下文件跑 `ruff check --fix` 自动清理 F401**（或加 noqa 后）：
- `veusz/windows/simplewindow.py`（已加 noqa）
- `veusz/veusz_main.py` ImportThread.run()（三导入，HEAD 本就正确）
- `veusz/qtall.py` loadUi/sip fallback
- `tests/runselftest.py`（`import veusz.dataimport` + `import veusz.windows.mainwindow`，HEAD 本就正确）
